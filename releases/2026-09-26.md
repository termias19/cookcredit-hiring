# Public hiring hardening release — 2026-09-26

Live: https://hiring.cookcredit.com

Removed invited-testing wording from public hiring screens and the hiring introduction. Employer access still requires owner approval; approved employers have five open roles. Payments and automatic hiring decisions remain disabled.

Revoked Firebase sessions are checked with a maximum 30-second cache. Private applicant media/CVs retain their 30-day expiry; company branding is excluded. Expired/missing CVs return a clear unavailable response. Failed or stalled email/webhook queues generate structured events and owner alerts, even when later dispatcher batches are empty.

API errors carry a request ID and deployed Git commit. See OPERATIONS.md for Cloud Logging filters, investigation and rollback. No credentials, private handoffs, applicant data or historical local Git history were published.

Validation: release build passed 545 backend tests (17 skipped), 55 frontend tests, and an isolated 400-request metadata probe with no request failures against 10,000 seeded records. Read/create p95 was 428/852 ms; maximum observed in-flight requests was 48, despite configuring 100 worker clients. Shared Redis limits passed across two independent processes. Production readiness, anonymous access denial, foreign CORS rejection and release headers passed. All 32 assessment assets and 32 unrelated main-site assets were preserved.

The first CI run exposed a missing CI-only PyYAML dependency; the follow-up CI run passed. Application source at the release commit and passing CI commit is identical. One initial verification build was canceled after finding Docker argument order incorrect; the corrected immutable-source build passed before deployment.

## Capacity boundary

This is a bounded public deployment, not a mass-traffic certification. Cloud Run remains capped at three instances with a shared-core zonal SQL database and BASIC Redis. SMTP dispatch is bounded to five messages per batch and subject to Google account quotas. Before a mass signup campaign: establish a traffic/budget target, provision adequate database/Redis availability and transactional-mail capacity, then run sustained integrated upload/processing/email/webhook load tests. Fresh signed-in production applicant acceptance is still required. Skipped tests and metadata probes do not certify those workflows.

Exact image, versions and rollback identifiers are in 2026-09-26.json. Restore code versions without restoring or deleting user data.
